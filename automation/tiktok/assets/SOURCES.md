# Éléments visuels fixes

- Icône Nevi : mobile/assets/icon.png, fournie par le propriétaire de l'application.
- Google Traduction : fiche App Store 414706506, artworkUrl512 via iTunes Lookup.
- DeepL : fiche App Store 1552407475.
- Apple Traduire : fiche App Store 1514844618.
- Microsoft Translator, iTranslate, Reverso, Papago et Yandex : URLs officielles artworkUrl512 dans icons/sources.json.
- Globe : caractère Unicode U+1F30D, rendu sur macOS avec Apple Color Emoji. Le fichier n'est pas présenté comme une photographie libre de droits.
- Les icônes identifient les applications citées ; aucune affiliation ou approbation de leurs éditeurs n'est revendiquée.
- Photographies automatiques : auteurs, licences, URLs et dates de vérification enregistrés dans le manifeste de chaque carrousel. Les crédits CC BY apparaissent dans la légende.
